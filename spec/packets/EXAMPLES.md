# Packet examples

Complete packets in both wire forms, generated by aolib-ts and checked against aolib-go. The FantaCode and JSON forms of each example decode to the same packet.

## MS (client to server), full

Objection with a preanim, desk slam SFX, evidence, pairing, offset, screenshake and a realization effect.

```
MS#2#pointing#Phoenix#handsondesk#The defense has evidence <num>3 <and> it changes everything!#def#sfx-deskslam#2#12#1#2#3#0#1#4#Wright#4#-10&0#0#0#1####0#realization||sfx-realization#%
```

```json
{
  "$header": "MS",
  "desk_modifier": "hide_during_preanim",
  "preanim": "pointing",
  "character": "Phoenix",
  "emote": "handsondesk",
  "message": "The defense has evidence #3 & it changes everything!",
  "side": "def",
  "sfx_name": "sfx-deskslam",
  "emote_modifier": "preanim_and_objection",
  "char_id": 12,
  "sfx_delay": 1,
  "shout_modifier": "objection",
  "evidence_id": 3,
  "flip": "none",
  "realization": true,
  "text_color": "blue",
  "showname": "Wright",
  "paired_charid": 4,
  "offset": {
    "x": -10,
    "y": 0
  },
  "noninterrupting_preanim": false,
  "sfx_looping": false,
  "screenshake": true,
  "frames_shake": "",
  "frames_realization": "",
  "frames_sfx": "",
  "additive": false,
  "effect": {
    "name": "realization",
    "folder": "",
    "sound": "sfx-realization"
  }
}
```

## MC (client to server)

Music change request that fades in and keeps the previous track's position. `effects` is a bitfield on the wire (`5` = fade in + sync position).

```
MC#Cornered.opus#12#Wright#5#%
```

```json
{
  "$header": "MC",
  "name": "Cornered.opus",
  "char_id": 12,
  "showname": "Wright",
  "effects": {
    "fade_in": true,
    "fade_out": false,
    "sync_position": true
  }
}
```

## MC (server to client)

Music change broadcast, looping on channel 0, fading the old track out and the new one in (`3`).

```
MC#Cornered.opus#12#Wright#1#0#3#%
```

```json
{
  "$header": "MC",
  "name": "Cornered.opus",
  "char_id": 12,
  "showname": "Wright",
  "looping": true,
  "channel": 0,
  "effects": {
    "fade_in": true,
    "fade_out": true,
    "sync_position": false
  }
}
```

## CC

Character select request.

```
CC#0#12##%
```

```json
{
  "$header": "CC",
  "player_id": 0,
  "char_id": 12,
  "char_password": ""
}
```

## PV

Character select confirmation. `_cid` is a fixed padding slot and still appears in the JSON envelope.

```
PV#5#CID#12#%
```

```json
{
  "$header": "PV",
  "player_id": 5,
  "_cid": "CID",
  "char_id": 12
}
```

## RT (client to server)

Guilty verdict. JSON names the animation; the wire splits it into `judgeruling` and variant `1` (see `CODECS.md`).

```
RT#judgeruling#1#%
```

```json
{
  "$header": "RT",
  "animation": "guilty",
  "name": ""
}
```

## SC

Character list; each `name&desc&evidence` object is one slot.

```
SC#Phoenix&Defense attorney&#Edgeworth&&#Maya&&#%
```

```json
{
  "$header": "SC",
  "char_data": [
    {
      "name": "Phoenix",
      "desc": "Defense attorney",
      "evidence": ""
    },
    {
      "name": "Edgeworth",
      "desc": "",
      "evidence": ""
    },
    {
      "name": "Maya",
      "desc": "",
      "evidence": ""
    }
  ]
}
```

## SM

Music list (areas and tracks share the list in the legacy protocol).

```json
  "music_list": [
    {
      "name": "Courtroom"
    },
    {
      "name": "Basement"
    },
    {
      "name": "== Music =="
    },
    {
      "name": "Cornered.opus"
    },
    {
      "name": "Objection.opus"
    }
  ]
}
```

Area status for three areas (see `CODECS.md`).

```json
{
  "$header": "ARUP",
  "update_type": "status",
  "update_data": [
    "IDLE",
    "CASING",
    "RP"
  ]
}
```
